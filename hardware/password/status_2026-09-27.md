# Password モジュール 現状整理(2026-09-27、同日にハブ回答を反映して更新)

担当: Password 設計セッション。ハブ(OSC2026)依頼による**棚卸し**。新しい設計変更・部品調査は行っていない。
例外として、①自分の納品物の主張の裏取り(SSD1315データシート、パズル生成アルゴリズムのスクリプト検証、設計メモ§8の誤りの訂正)と、
②ハブの回答で決まった共通ルールの反映(バルクコンデンサ、PWR_FLAG)だけを行った。
読み直した資料: `ハブ連絡事項.md`(9/27更新版)、`予算概要.md`(9/24)。詳細な設計は `password_design_notes.md` が正本。

PWR_FLAG)は回路図・BOMに反映済み。表示窓とボタンの位置ずれは**2026-09-27にユーザー判断が出て解決済み**(そのまま許容、
設計変更なし)。ユーザー判断待ちは残り1件(1桁あたりの候補文字数=6文字でよいか)。

## 4. 既知のリスクと、過去に自分が訂正した誤り

### 現在のリスク
1. **OLED窓の位置・寸法は仮**。秋月ページに窓寸法の記載が無く、「一般的な0.96インチ品の21.7×10.9mm、基板中央」と仮定しているだけ。実際の基板では窓が中心からずれていることが多く、パネルの窓切り欠きの位置に直結する。
2. **ブリングアップは未実行**: スクリプトは構文確認のみ。`ssd1306.py`の入手・アップロードが前提。
3. **部品寸法の根拠が弱い**: タクトスイッチの6.2mm角・端子ピッチ4.5mm、OLED基板27×24.7mmは秋月ページの文面(自動要約の取得を含む)で、データシートの図面では確認していない(共有記憶の方針: 形状に関わる値はデータシートで確認)。KiCadのフットプリント`SW_PUSH_6mm`がDTS-63の端子配置と一致するか、`CP_Radial_D6.3mm_P2.50mm`が実際のC1と合うかも未確認(PCB化する場合に必要)。
4. **「1桁6文字」は公式資料に無い設計判断**。
5. パネル裏でC1(電解φ6.3mm級)の高さが筐体と干渉しないかは未確認(ケース担当待ち)。
6. 図面の見た目は整理したが、コネクタのピンが左向きのため配線がJ1/J2の本体を横切る。スイッチ11個が2.54mmピッチで密なため、シンボルの一部が重なって見える(電気的には問題なし。清書は任意)。

(9/27に解消: ERC 3件、バルクコンデンサ未実装、3V3(OUT)許容電流の未確認、LED電流・平均電流の測定手順の欠落。)
(9/29に解消: 桁の文字と▲▼が揃わない問題(ユーザー決定、そのまま許容)、穴の中心位置・寸法の未確認(φ2.6、縁から9mmに確定、干渉なし)。)

### 過去に自分が訂正した誤り
1. **「34語」**: WebFetchの要約の誤りを、公式マニュアル画像で数え直して**35語**に訂正(設計メモに注意書きあり)。
2. **配置(9/24)**: 前版の縦寸法「合計77mm・余裕3mm」は保守的すぎ、実際は57.65mm・余裕約22mmに訂正。さらに前版の図が「5文字が各ボタンの真上に並ぶ」誤解を与えていたのを§2-5で訂正し、ハブ経由で報告した。
3. **状態LEDの位置**: 当初(61, 8)は穴中心11.6mmで干渉するため(58, 8)に変更。
4. **KiCad生成時の電源フラグの誤配置**: フラグを±2.54mmずらしたところ、隣接ピン(pin3のGNDフラグがpin2のUART RX)に重なって誤接続になった。自作の線分重なりチェックとERCの警告で納品前に発見して修正済み。
5. **ERC指摘を「許容」と書いた誤り(9/27に訂正・解消)**: `power_pin_not_driven`の3件を「既知の許容範囲」と書いたが、根拠は「keypadにも出る」ことと私の推測だけだった。原因はPWR_FLAG未配置で、Morse Code担当の知見どおり各電源ネットにPWR_FLAGを置いてERC 0件にした。9/24のハブへの報告(「配線ミスではないKiCad標準の指摘」)も訂正済み。
6. **ピンが別ワイヤーの途中に乗る潜在的な誤り(9/27に発見・修正)**: 初版ではJ1のPin4(GND)がOLEDのSDA配線の途中に乗っていた。ネットリストでは別ネットで電気的には正しかったが、編集や別バージョンでGND−SDA短絡になりうる。9/24の自動チェックが線分同士しか見ていなかったため見逃していた。J1を移動して解消し、チェッカーを拡張した。9/24の報告の「異なるネット間の線分重なりも自動チェック済み」はこの点をカバーしていなかった。
7. **電流の記述**: 設計メモ§5の「状態LEDは数十mA」は誤りで約4〜8mAに訂正(9/27)。
