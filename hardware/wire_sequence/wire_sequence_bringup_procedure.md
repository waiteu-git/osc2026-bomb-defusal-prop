# Wire Sequence モジュール 動作確認(ブリングアップ)手順

作成日: 2026-09-24。回路図 `wire_sequence.kicad_sch`(ネットリストで各ネットを部品・ピンごとに確認済み)とスクリプト [wire_sequence_bringup_test.py](wire_sequence_bringup_test.py) の対応を取って書いている。本番のファームウェア(ページ判定・ストライク通知)はソフト担当が別途実装するので、ここでは配線・部品の確認だけを行う。

## 1. 必要なもの
- Raspberry Pi Pico 2(ヘッダー実装済み、MicroPython書き込み済み)、PC + Thonny、USBケーブル、ブレッドボード、ジャンパー線
- ワイヤー8本分: 2ピンヘッダー(またはジャンパーキャップ)を8組。**本番の端子台(ねじ式/プッシュ式)は型番未確定**なので、ここでは既存のwiresモジュールのブリングアップと同じく、ジャンパーキャップの抜き差し(またはワイヤーを渡した端子)で「ワイヤーあり/切断」を模擬する
- 抵抗: 1kΩ×8(信号線の直列)、10kΩ×8(外付けプルアップ)、330Ω×5(NeoPixelデータ線1本+ステージLED4個)、47Ω×1(状態LED)
- LED: 5mm赤×4(ステージ、OSR5JA5E34B)、3mm緑×1(状態LED、OSG58A3131A)
- タクトスイッチ×2(UP/DOWN)
- NeoPixel×8: 本番部品はWS2812B(V5)チップまたはAE-WS2812Bモジュール。**仮組みでは、手持ちのAE-WS2812B-STICK8(8個、迷路モジュールで使用)を流用してよい**(ただしSTICK8のIO電圧は2.7V〜で、単体のAE-WS2812B(3.5V〜)や本番のV5チップとは仕様が違うため、3.3V直結のマージンの確認は本番部品でやり直す。6章)
- テスター(電圧測定用)

## 2. 配線表(回路図・スクリプトと一致)

| 信号 | GPIO | Pico物理ピン | 部品・つなぎ方 |
|---|---|---:|---|
| W1〜W4 切断検知 | GPIO2〜5 | 4,5,6,7 | ワイヤーの信号極 → 1kΩ → GPIO。GPIOと3V3(物理ピン36)の間に10kΩ。GND極はGND |
| W5〜W8 切断検知 | GPIO6〜9 | 9,10,11,12 | 同上 |
| NeoPixelデータ | GPIO10 | 14 | 330Ωを介して1個目のDIN。DOUT→次のDIN(W1..W8の順)。VDDは5V、VSSはGND |
| ステージLED 1〜3 | GPIO11〜13 | 15,16,17 | 各330Ω→LEDアノード、カソード→GND |
| ステージLED 4 | GPIO14 | 19 | 330Ω→LEDアノード、カソード→GND |
| UPボタン | GPIO15 | 20 | 片方をGPIO、もう片方をGND(内部プルアップ)。4本足のうち同じ辺の2本は常時導通なので、向かい合う辺から1本ずつ使う |
| DOWNボタン | GPIO16 | 21 | 同上 |
| 状態LED(緑) | GPIO17 | 22 | 47Ω→LEDアノード、カソード→GND |
| UART0 TX / RX | GPIO0 / GPIO1 | 1 / 2 | 通常は未接続。ループバック確認のときだけ、1と2を短絡 |
| 5V | - | 40(VBUS) | **ブリングアップではUSBの5V(VBUS)をNeoPixelのVDDに使う**。本番ではJSTのPin3(ホストの5V)をVSYS(物理ピン39)へ入れる |
| 3.3V | - | 36 | プルアップの電源(3V3 OUT) |
| GND | - | 3,8,13,18,23,28,33,38,42のいずれか | 共通GND |

- 各NeoPixelのVDD-GND間に0.1µF、チェーン先頭のVDD-GND間に100µF程度の電解コンデンサを付ける(仮組みでSTICK8を使う場合は基板側に付いているので不要)。
- 回路図には、NeoPixelのVDDを **+5V → 0Ωリンク(R23、既定) または 1N4007(D10)を経由して NEO_VDD** にするランドを入れてある。**WS2812B(V5)チップまたはSTICK8で試すときは、最初は0Ωリンク(ジャンパー線でつなぐだけ)で始める。単体のAE-WS2812Bモジュール(旧世代、DIN 3.5V〜)を使うときは、最初からR23を外してD10(1N4007)を実装する(6章6.)**。

## 3. 実行と期待される出力
1. Thonnyで `wire_sequence_bringup_test.py` を開いて実行(F5)。
2. 起動直後、状態LEDが0.15秒間隔で3回点滅する(生存確認)。REPLに `=== Wire Sequence bring-up test start ===`。
3. ステージLEDが1〜4の順に0.25秒ずつ点灯し、全消灯する。REPLに `ステージLED 1 点灯` 〜 `ステージLED 4 点灯`。
4. NeoPixelが **W1→W8の順に1個ずつ**、弱い白で点灯する。REPLに `NeoPixel 1 (W1) 点灯` 〜 `NeoPixel 8 (W8) 点灯`。順序が入れ替わる、途中で止まる場合は、DOUT→DINの配線を確認する。
5. 全灯で赤→緑→青→白の順に点灯する(色チャンネルの確認)。REPLに `全灯: 赤` など。
6. 5秒間、青と赤を高速に切り替える(3.3V直結のマージン確認)。**チラつき、色ずれ、消えるLEDが無いか目視する**(6章)。
7. `--- ワイヤー・ボタン監視開始(ワイヤーを切る/外す、UP/DOWNを押して確認してください) ---` に続き、8本の状態が並ぶ。全ワイヤーを渡した状態なら `W1(GPIO2): 接続` 〜 `W8(GPIO9): 接続`。NeoPixelは、割り当て色(赤・青・黒=弱い白)で光る。
8. ワイヤーを1本外す(または切る)と、約60ms後にREPLへ `W3(GPIO4, 色=black): 切断` のように出て、そのNeoPixelだけ消える。戻すと `接続` が出て再点灯する。**切った(外した)ワイヤーの番号とNeoPixelの番号が一致すること**を確認する(W1が最上段)。
9. UPボタンを押すと `UP (GPIO15) pressed`、DOWNボタンで `DOWN (GPIO16) pressed`。DOWNでステージLEDの点灯数が1つずつ増え(最大4)、UPで減る。押している間だけ状態LEDが点灯する。
10. (任意)JSTのPin1とPin2(GPIO0/1)を短絡し、スクリプト先頭の `UART_LOOPBACK_TEST = True` にすると、`UART loopback: 送信 b'WSEQ' -> 受信 b'WSEQ'` と `OK` が出る。

## 4. うまくいかないとき
| 症状 | 確認すること |
|---|---|
| 全ワイヤーが「切断」のまま | 3V3(物理ピン36)への10kΩ、GND極のGND接続。外付けプルアップを付けない仮組みでは、スクリプト先頭を `WIRE_PULL = Pin.PULL_UP` にする |
| 全ワイヤーが「接続」のまま | 信号極とGND極が最初から短絡していないか(隣の端子とのショート、断片の接触) |
| あるワイヤーだけ反応しない | そのGPIOの1kΩと10kΩ。回路図の対応は `W1_IN`〜`W8_IN`(GPIO2〜9) |
| NeoPixelが全く光らない | VDD(5V)、GND、DINの向き(DIN側がGPIO10)。データ線に330Ωが入っているか |
| NeoPixelが途中から光らない | 光らない個体の手前のDOUT→DIN、電源 |
| 状態LEDが暗い/点かない | OSG58A3131Aのデータシート上のVf=2.9/3.1/3.6Vは20mA時の値で、3.3V駆動+47Ωでは数mAしか流れない。Vfが高い個体は暗くなる。47Ωの両端の電圧(=電流×47Ω)で電流を確かめ、極端に暗ければ別個体で確認する |

## 5. 切断作業の確認(実物)
- 実物のワイヤー(ETFE線など)を端子台に挿し、実際にニッパー/ハサミで切る。**切断作業のしやすさ**(通路6.5mmにニッパーの先端が入るか)、**切断後の断片が隣の端子に触れないか**(仕切り板の効果)を確認する。
- 交換の所要時間(切れた1本を新しい線に取り替えるのに何秒かかるか)を計る。端子台の型番(ねじ式/プッシュ式)を3モジュールで統一するための判断材料になる。

## 6. NeoPixelの3.3V直結マージンの確認(ハブ依頼)
Pico 2の3.3V出力でNeoPixelのDINを直接駆動する構成なので、届いた部品と実電圧で余裕があるかを測って確認する。

1. **部品の版を記録する**: WS2812B(V5)チップの袋・リール・データシートの版(2019〜2020年版のV5か、2021年以降の「WS2812B-V5/W」か)。前者はVIH=2.7V固定、後者はVIH=0.63×VDD(VDD=5.0Vで3.15V、3.3Vに対する余裕は0.15V)。AE-WS2812B(単体モジュール)は旧版でVIH=0.7×VDD(5Vで3.5V)なので**3.3V直結は規格外**。
2. **実際のVDDを測る**: 全灯テスト(手順3の5、`MAX_BRIGHTNESS=20`)の点灯中に、1個目のNeoPixelのVDD-VSS間の電圧をテスターで測る。5Vのレールからポリスイッチ・配線・0Ωリンクで落ちた値が実際のVDDになる(USB給電のブリングアップとホスト給電の本番で値が違うので、本番の給電でも測る)。
3. **判定**: V5/Wなら VIH=0.63×VDD が3.3Vを十分に下回ること(目安: VDD≦5.0V なら余裕≧0.15V)。旧版のV5(2.7V)なら、VDDが規格範囲(3.7〜5.3V)内であればよい。
4. **目視確認**: 手順3の6(5秒の高速書き込み)で、チラつき・色ずれ・消えるLEDが無いこと。念のため、`DIN_SOAK_SECONDS` を60秒に変えて再確認する。
5. **不合格だったら**: 回路図の **R23(0Ωリンク)を外し、D10(1N4007)を実装**する。VDDが約0.7V下がって約4.3Vになり、VIH(0.63×4.3≒2.7V、または0.7×4.3≒3.0V)が下がって3.3Vに対して余裕ができる。NeoPixelのVDD下限(V5チップ3.7V、AE-WS2812Bモジュール3.5V)を割らないことを、VDDを測って確認する。それでも足りなければ、1個目のDINの手前にTTL入力のレベルシフタ(SN74AHCT125N等、価格未確認)を入れる。
6. **AE-WS2812Bモジュールを使う場合**(手配線の案(b)): 単体モジュールは旧版なので、**最初から** 5.のダイオード降圧(D10実装、R23なし)かレベルシフタが前提。VDDを約4.3Vにして、VIH=0.7×4.3≒3.0Vで3.3Vに対して約0.3Vの余裕を確認する。

## 7. 合格の目安
- 手順3の1〜9が全て期待どおり。8本すべてで、ワイヤー番号とNeoPixel番号・GPIO番号が一致する。
- 6章の確認で、実電圧・目視ともに余裕がある(不合格ならD10に切り替えて再確認)。
- 切断作業と断片の接触について、5章で問題が無い。
